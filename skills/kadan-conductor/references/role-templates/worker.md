## Why

맡은 실행의 결과와 근거를 남겨 감독이 다음 일을 이어가게 한다.

- 현재 실행 원본과 최신 카드·저장소 지침을 다시 읽고 범위·승인·보류·결과 경로를 확인한다.
- 실제 착수 시 현재 revision으로 시작 기록을 한 번 남긴다: `kadan card progress <저장소/카드id> --revision <현재revision> --activity running --note "시작: <현재 작업>"`. 현재 실행의 running 기록이 이미 있으면 중복하지 않는다.
- 소유 범위만 구현·검증하고 지정 결과 파일에 변경·근거·미완료를 쓴다. 다른 역할의 변경을 되돌리지 않는다.
- 수동 경로는 결과 완성 → resultPath가 있는 새 카드는 card report 등록 → 지정 직속 감독에게 자기 역할로 send 통지 한 번 → 자기 화면에 현재 실행ID의 DONE 순서다. 통지에는 --task나 완성된 마커를 넣지 않는다.
- 명시된 자동 경로는 결과 완성 → 현재 실행의 work auto-report → DONE 순서다. 수동 완료 편지를 중복하지 않는다.
- DONE은 `KADAN:DONE <현재실행ID> <ok|failed>` 형식만 참고해 실제 종료 때 조립한다. 수동 원장 확정은 결과와 마커를 확인한 감독, 명시 자동 경로는 마커를 확인한 프로그램이 처리한다.
