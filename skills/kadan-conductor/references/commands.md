# 사용자의 말 → kadan 명령

아래 표의 `kadan`은 설치된 명령(`npm link`)을 뜻한다. PATH에 없고 소스 저장소에서
직접 돌리는 판이면 설치로 환경을 바꾸지 말고 `node <저장소>/src/cli.mjs`로 치환한다.

| 사용자의 말·옛 동작 | 카단 라이트에서 할 일 |
|---|---|
| 카드 만들어 | `docs/daily/<날짜>/card-<id>.md` 작성 |
| 지금 역할 보여줘 | `kadan status` |
| 판 구성 보여줘 | `kadan tree` |
| 관제 화면 열어줘 | `kadan wall` |
| 화면 봐줘 | `kadan read <역할> [--lines N]` |
| 원장 보여줘 | `kadan log` |
| 새 작업자 띄워 | `kadan start <판>-작업자 --profile worker --cmd "<실행기 명령>"` |
| 카드 보내 | `kadan send <역할> --task <카드id> "<카드 경로>를 읽고 수행…마커 형식…"` |
| 끝날 때까지 봐 | `kadan wait <역할> [--timeout 초] [--quiet 초]` |
| 창에서 직접 볼게 | `kadan attach <역할>` |
| 역할 멈춰 | `kadan stop <정확한 역할>` |
| 검수 붙여 | `kadan start <판>-검수자 --profile reviewer --cmd "<실행기 명령>"` → gajae 검수 카드 send → 응답 종료·완료 편지 수신 |
| 수정 다시 시켜 | 같은 카드의 발견 전문을 넣은 수정 카드 send |
| 죽은 역할 다시 세워 | 기존 역할 stop → `<역할>-2` start → 같은 카드 send |
| 결정이 필요해 | 원장 명령 없음. 감독이 대화로 사용자에게 질문 |
| 병렬 충돌을 막아 | 충돌 사유를 카드에 쓰고 필요할 때만 `git worktree add` |

새 역할은 [역할별 프로필 명령](worker-creation.md#새-역할의-프로필)을 따른다.
기존 세션은 프로필을 넣기 위해 재시작하거나 소급 변경하지 않는다.

## 카드 파일 최소 항목

```markdown
## Why
## 읽고 시작할 것
## 시작 기록
## 범위
## 금지
## 합격 기준
## 결과 파일
## 완료 통지 수신자
## 완료
```

실제 계약은 [카드 템플릿](card-template.md)을 사용한다. 자동 역할 지침이 붙어도 위 필수 항목을 생략하지 않는다.

카드 id는 파일명이다. 결과 파일은 보통 `.staging/result-<카드id>.md`다.

## 마커 지문

```text
끝나면 결과를 <결과 파일>에 쓰고 마지막 줄에 완료 마커를 출력하라.
형식은 KADAN:DONE <카드id> <ok 또는 failed>, 카드 id는 <카드id>.
판정과 필수 근거를 썼으면 사소한 문장 다듬기로 DONE을 늦추지 않는다.
결과 파일의 사소한 오탈자는 보고에 남기고 즉시 마커를 출력한다.
```

실제 카드 ID와 결과를 조립한 완성된 마커 문자열은 지문에 넣지 않는다.
