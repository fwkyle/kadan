# 상황별 길잡이

## Why

카단을 쓰는 사람이 "이걸 하고 싶은데 뭘 치지?"에서 막히지 않게, 하고 싶은 일에서 시작해 명령 한 줄과 자세한 문서까지 한 장으로 잇는다.

## 읽는 법

- 항목마다 같은 순서의 네 줄이다: **말 한마디**(AI나 디스코드에 말로 시키는 길, 없으면 화면에서 누르는 곳), **명령 한 줄**, **주의**, **자세한 문서**.
- `<역할>`은 세션 이름에서 `kadan-`을 뺀 부분이다. 예시의 `my-app-감독` 같은 이름은 지어낸 것이다.
- 모든 옵션은 [명령어 사전](commands.md)에 있다. 대시보드 메뉴 **길잡이**도 이 문서를 그대로 보여 준다.

## 하던 대화를 카단으로 옮기기

- **말 한마디**: 대화 중인 AI에게 "감독으로 올려" 또는 "맡겨 놓고 갈래". 카단 스킬(`kadan-go`)이 연결된 대화에서만 통한다.
- **명령 한 줄**: `kadan adopt <감독이름> --model <모델>` — 대화를 시작한 폴더에서 친다.
- **주의**: 길이 셋이고 쓰는 때가 다르다. (1) `kadan adopt`: 카단 밖(앱·터미널)에서 하던 대화를 처음 카단 감독으로 들일 때. 대화 전체를 복제해 새 감독으로 열고 현재 권한도 이어받는다. 새 감독이 인수를 확인한 뒤 정확히 찾은 원본 로티 탭만 닫는다. 인수 확인이 끝나기 전에 원래 탭에 입력하면 확인이 거절되니, 옮긴 뒤 원래 탭에는 입력하지 않는다. (2) `kadan start <역할> --profile conductor --cmd "claude --resume <대화ID> --model <모델>" --reason "<이유>"`: 복제하지 않고 같은 대화를 그대로 카단 역할로 열 때. 권한을 자동으로 복사하지 않으니 필요한 권한 옵션은 명령에 직접 넣고, 첫 안내가 가지 않으니 역할과 할 일도 직접 알려 준다. 인수 확인과 원본 탭 정리 절차가 없다. (3) `kadan handover <선임> --to <후임> …`: 이미 카단에 등록된 역할의 담당을 다른 역할로 바꿀 때. 대화가 아니라 문서와 기록으로 넘기므로, 선임의 대화에만 있고 어디에도 적지 않은 맥락은 빠질 수 있다.
- **자세한 문서**: [대화 옮기기 안내의 세 가지 길 비교](adopt.md#세-가지-길-비교), [인계 안내](handover.md), [명령어 사전](commands.md)

## 역할 다시 띄우기

- **말 한마디**: 없음. 화면에서는 대시보드 **전략 맵**에서 유닛을 누르면 열리는 옆 칸의 **다시 띄우기**(이유 칸 필수).
- **명령 한 줄**: `kadan restart <역할> --reason "<이유>"`
- **주의**: 대화 기억·우편·맡은 카드는 그대로 두고 프로그램만 다시 띄운다. 응답을 만드는 중이거나 방금 사람이 입력했으면 끄지 않고 거절하니 잠시 뒤 다시 한다. `--force`는 그 확인을 건너뛰는 옵션이라 사람이 직접 확인했을 때만 쓴다(역할 AI는 쓰지 않는다).
- **자세한 문서**: [명령어 사전의 restart 자세히](commands.md#kadan-restart-자세히)

## 감시기·대시보드 갱신하기

- **말 한마디**: 없음. 화면에서는 **전략 맵** 아래 **기반 세션** 묶음의 **다시 띄우기**.
- **명령 한 줄**: `kadan stop watch`, `kadan stop 대시보드` 다음에 `kadan up --hidden`
- **주의**: 대시보드 화면 코드(`gui/`)가 바뀌었으면 다시 띄우기 **전에** `npm --prefix gui ci && npm run build:gui`로 화면을 먼저 빌드한다. 빌드 없이 다시 띄우면 바뀐 화면이 보이지 않는다. `kadan restart`는 AI 역할의 대화를 이어 여는 명령이고, 비서를 끌 때는 `kadan stop 비서`다.
- **자세한 문서**: [대시보드 구조와 개발](dashboard-react.md), [흐름 지도](flows.md), [감시 안내](watch-overview.md)

## 모델·프리셋 바꾸기

- **말 한마디**: 없음. 화면에서는 대시보드 **실행 모델 설정**에서 역할별 값을 고치고 **프리셋 저장**, 또는 프리셋 전환.
- **명령 한 줄**: `kadan runners set worker --runner <실행기> --model <모델> --effort <강도> --revision <N> --reason "<이유>"` — 프리셋을 통째로 바꿀 때는 `kadan runners preset <이름> --revision <N> --reason "<이유>"`
- **주의**: 지금 값과 `--revision`에 넣을 숫자는 `kadan runners show`로 본다. 바꿔도 이미 떠 있는 세션은 그대로이고 다음에 띄우는 역할부터 적용된다. 검수자는 작업자와 다른 계열 모델이어야 저장된다.
- **자세한 문서**: [실행 모델 설정](runner-settings.md)

## 비교 모드 켜고 끄기

- **말 한마디**: 없음. 화면에서는 **실행 모델 설정**의 **비교 모드** 절에서 프리셋을 고르고 **비교 모드 켜기** · **비교 모드 끄기**.
- **명령 한 줄**: `kadan runners compare on --presets <프리셋A>,<프리셋B> --revision <N> --reason "<이유>"` — 끌 때는 `kadan runners compare off --revision <N> --reason "<이유>"`
- **주의**: 켜면 새로 띄우는 작업자가 목록의 프리셋을 번갈아 쓴다. 비교 중인 프리셋은 고치거나 지울 수 없으니 먼저 끈다. 지금 상태는 `kadan runners compare show`, 결과는 `kadan runners report`로 본다.
- **자세한 문서**: [실행 모델 설정의 비교 모드](runner-settings.md#비교-모드)

## Autopilot 켜기

- **말 한마디**: 디스코드 #비서 채널에 `잘게`(끌 때는 `일어남`). `잘게 3시간`, `잘게 07:30까지`, `잘게 자동`도 받는다.
- **명령 한 줄**: `kadan autopilot on "<맡기는 말>" --for 8h` — 끌 때는 `kadan autopilot off`, 지금 상태는 `kadan autopilot status --text`
- **주의**: 새 권한을 주는 것이 아니다. 감독들은 이미 승인된 범위 안에서만 일한다. 기본 8시간, 최대 12시간이고 `kadan autopilot off`·끝 시각·사람이 새로 답한 결정 중 먼저 온 것으로 꺼진다. 단계를 안 주면 Cruise이고, 스스로 찾아 진행하는 단계는 `--level autopilot`이다.
- **자세한 문서**: [결정 기록의 밤 위임](decisions.md#밤-위임-autopilot-2026-10-23), [디스코드 한 마디](discord-chat.md#autopilot-한-마디-잘게일어남), [저장소별 자동 머지 정책](autopilot-repo-cards.md)

## 결정 답하기

- **말 한마디**: 디스코드 레포 포럼의 요청 글에 번호나 선택지 문구 그대로 답한다. 화면에서는 대시보드 **내 결정**에서 고른다.
- **명령 한 줄**: `kadan decision answer <결정ID> --revision <N> --choice "<선택지>"` — 열린 결정은 `kadan decision list --status open`
- **주의**: 답은 사람 명의로만 기록된다(역할 AI는 답하지 못한다). `--revision`에 넣을 숫자는 `kadan decision show <결정ID>`로 본다. 답했다고 카드 상태가 저절로 바뀌지는 않고, 요청한 슈퍼감독이 답을 읽고 이어서 처리한다.
- **자세한 문서**: [사용자 결정 요청](decisions.md), [디스코드에서 결정 답하기](discord-chat.md#디코에서-결정-답하기)

## 막혔을 때 점검하기

- **말 한마디**: 없음.
- **명령 한 줄**: `kadan doctor`
- **주의**: 읽기 전용이다. 막힌 곳과 풀려면 칠 명령을 한 줄씩 보여 줄 뿐 아무것도 고치지 않는다. 막힌 곳이 있으면 종료 코드가 1이다. 명령 목록이 필요하면 `kadan help --all`.
- **자세한 문서**: [명령어 사전](commands.md)

## 일이 쌓이면 감독을 나눈다

- **말 한마디**: 없음. 슈퍼감독이 스스로 한다.
- **명령 한 줄**: 설정 이름과 명령은 장치 PR이 머지된 뒤 채운다(아직 자리만 둔다).
- **주의**: 한 감독의 진행 중 업무가 기준 개수(기본 3, 사용자가 바꿀 수 있음) 이상이고 고칠 파일이 서로 겹치지 않으면, 슈퍼감독이 새 감독을 띄워 일을 나눠 맡긴다. 사용자 승인은 필요 없다.
- **자세한 문서**: [책임 관계 안내](hierarchy.md)
