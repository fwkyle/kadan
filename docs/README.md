# 카단 라이트 문서

## Why

[kyle]이 현재 운영 기준을 찾고, 글과 그림으로 같은 내용을 이해하게 한다.

## 문서 관리 방식

- **현재 기준은 `docs/주제.md`가 원본이다.** 바뀐 규칙·예외·근거를 이곳에 적는다.
- **그림이 필요한 주제는 `docs/주제.html`을 한 쌍으로 둔다.** Markdown과 HTML은 서로 연결하고 정책 날짜를 맞춘다. 의미가 바뀌면 같은 작업에서 둘 다 갱신한다. 모든 문서를 억지로 HTML로 만들지는 않는다.
- 그날의 변경·검증 기록(일지)은 작업장 전용 기록 레포에 둔다. 과거 판단과 증거는 그 시점대로 보존하고 현재 운영 기준은 아래 문서에서 읽는다.
- 다음 작업은 [TODO](TODO.md), 실제 업무·실행의 진행 기록은 기존 카단 카드와 원장에 둔다. 별도의 진행 원장을 만들지 않는다.
